# Integralfunction Sioyek

## How do I install these formulae?

`brew install integralfunction/sioyek/<formula>`

Or `brew tap integralfunction/sioyek` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "integralfunction/sioyek"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
